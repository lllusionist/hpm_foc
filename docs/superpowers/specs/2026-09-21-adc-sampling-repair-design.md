# ADC 采样修复设计

## 目标

让 ADC 采样在转换或 DMA 帧失败时行为确定，消除 ADC1 的触发歧义，并把 DMA 与模拟引脚
假设显式化，同时不改变 PWM 采样点和 FOC 控制算法。

## 范围

- ADC0 保持 PWM 触发（`TRG0A`），队列 `{IA, IB, IC}`，只在最后一项开中断，40 kHz 中断跑电流环。
- ADC1 改为两个软件触发队列：
  - `TRG0B`：`{VA, VB, VC, VBUS}`，任务 1 kHz 触发，只在最后一项开中断（不接 NVIC）。
  - `TRG0C`：`{IBUS}`，任务 1 kHz 触发，不开中断（纯轮询）。
- ADC1 只有通过完整、校验过的 DMA 帧才返回成功。
- ADC0 只有在通道、触发、序号元数据都正确时才接受该 DMA 帧。
- 两块 ADC 的 DMA 缓冲区都放到链接脚本提供的非缓存 BSS（`.noncacheable.bss`），并按抢占模式
  固定 192 字节（48 项）分配。
- PF27 / PF26 / PF21 / PF20 显式配置为模拟输入。
- IBUS 由 ADC1 `TRG0C` 采集，不再"不可用"。

## 非目标

- 选择最终 PWM 触发位置。
- 改变 ADC 采样周期、PWM 频率、电流重构或 FOC 增益。

## 关键硬件行为（上板实测）

- **抢占 DMA 固定使用 192 字节、每项 4 字节、每队列 4 项**。队列 `q` 的结果落在
  `TRG_DMA_ADDR + q*0x10`（`0A→+0x00`、`0B→+0x10`、`0C→+0x20`）。因此每个 ADC 的 DMA
  缓冲区必须按 48 项分配，否则会越界。
- **`TRG_CMPT_FLAG` 只为设置了 `INTEN` 的抢占队列置位**。不开 `INTEN` 的轮询队列
  （本设计的 IBUS `TRG0C`）不会置位，必须改用 DMA 结果元数据判断完成。
- 抢占模式 DMA 的 `CYCLE` 位恒为 1，不能用来区分新旧结果。改用"先把 `adc_ch` 清成无效值，
  再等它变成目标通道"的方式判新帧。
- `SEL_SYNC_AHB` 取决于 **ADC 控制器时钟与 DMA 总线时钟是否同源**（本设计两者都是 AHB0），
  与转换时钟分频 `/4` 无关，因此保持 `true`。

## 错误处理

- ADC1 读取失败保持调用方原状并累加诊断计数；连续 3 次失败触发 `FOC_FAULT_ADC` 停机。
- ADC0 坏帧不更新电流，累加坏帧计数；连续 3 次坏帧或连续 3 个周期无新帧触发 `FOC_FAULT_ADC`。
- 中点校准至少要拿到 16 组有效样本，否则不置 `FOC.adc_ready`，并禁止使能 / 启动校准。
- 任何未初始化或未校验的 ADC 数据都不得进入中点校准、电压计算或电流环。
