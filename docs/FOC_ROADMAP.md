# HPM5E31 FOC 学习路线：有感 → 无感 → MIT

> 项目：`D:\Desktop\FOC`（HPM5E00EVK / HPM5E31 RISC-V，FreeRTOS，SEGGER Embedded Studio）
> 目标：以"学习"为主线，把一套自研 FOC 从**有感闭环**做到**无感观测器**，最后做到 **MIT 力控（阻抗控制）**。
> 原则：**每一步都要有"真值"对照**（编码器 / 万用表 / 电源功率 / 示波器），这是学习效率的关键。

## 0. 现状盘点（已完成的能力）

### 0.1 硬件与平台

| 项 | 现状 |
|---|---|
| MCU | HPM5E31（EVK，Flash XIP），FreeRTOS |
| 构建 | SES 8.28：`foc/hpm5e00evk_flash_xip_debug/segger_embedded_studio/foc.emProject`（另有 CMake） |
| PWM | PWMv2 三相互补，**40kHz**，居中调制；死区 MCU **10ns**（FD6288 驱动器自带 ~100ns，**叠加**） |
| ADC0 | 抢占队列 3 项 `Ia/Ib/Ic`（IBUS 不在此队列），由 PWM 触发（counter==1，零矢量），16bit + AHB DMA，**40kHz 中断跑电流环** |
| ADC1 | 两个软件触发抢占队列：`TRG0B` 采 `VA/VB/VC/Vbus`、`TRG0C` 采 `Ibus`，任务 **1kHz**，均不接 NVIC 中断 |
| 编码器 | SPI（6 字节帧，21bit 在高位），5kHz，PLL(100Hz)，多圈位置，零位 + **128 项偏移 LUT** |
| 采样换算 | 电流 5mΩ+20×、母线电流 5mΩ+20×、母线/相电压 **15k/1k = 16:1**，VREF=3.3V（已用示波器核实 756mV@12.1V） |
| 上位机 | `tools/foc_scope`（Python tkinter 示波器，22 通道，5kHz，滚轮缩放 / 通道开关 / 增益偏置 / 滑条下发 / 配置记忆） |

### 0.2 固件能力

- **电流环**：40kHz，PI（`Kp = L·2πf`、`Ki = R·2πf`，`f = Config.current_ctrl_bw` 默认 1000Hz）+ 反电势前馈/解耦 + 电压饱和处理（`FOC_current()`）。
- **外环**：`Task_FOC` 5kHz，`foc_ctrl.c` 控制器（电流 / 速度 / 位置滤波 / 轨迹退化），回零待验证。
- **校准**：电阻（两点法 ~3.6Ω）→ 电感（正弦注入解调 ~1.31mH）→ 方向/极对数 → 编码器零位 + LUT → 磁链（两点法 ~1.5mWb，**偏高约 13%**）→ 自动存 Flash。
- **配置持久化**：`flash.c` 最后一个扇区 0x000ff000，magic + CRC32；`0x3F` 保存 / `0x3B` 恢复默认（**无二次确认，易误触发**）。
- **保护**：相过流（固定 20A）、母线欠压（默认 9V）、母线过压（默认 15V）；触发后置 `fault` 码、失能、退 IDLE。
- **观测流**：VOFA Justfloat，**22 通道 @5kHz**（ADC 中断 8 分频采样入环形缓冲，1ms 打包一包发出，≈440kB/s）。

### 0.3 已知问题 / 技术债（后续阶段要还）

| # | 问题 | 影响 |
|---|---|---|
| 1 | 编码器帧**无校验**，坏帧会让角度跳变 → 电流尖刺 | 有感可靠性 |
| 2 | ADC 单点坏值（DMA 与 ISR 抢读）未做防护 | 偶发电流尖刺 |
| 3 | 死区 MCU 10ns + 驱动 ~100ns **叠加** | 低电流线性度、R 校准截距 ~0.175V |
| 4 | 磁链校准偏高 ~13%（简单两点法） | 前馈/观测器精度 |
| 5 | 母线电流改由 ADC1 `TRG0C` **独立软件队列（1kHz）** 采样，不再与 PWM 零矢量同步；仍建议运放输出加 RC 滤波 | Ibus 目前只做监测与显示，不能保护 |
| 6 | 无看门狗；`0x3B` 无确认；命令无应答 | 可靠性 |
| 7 | PROFILE（轨迹）模式退化成位置滤波；ANTICOGGING（0x28）未实现 | 功能缺口 |
| 8 | 速度环/位置环未整定验证 | 阶段 0 收尾项 |

## 9. 专项：三相电流采样坏点（已结案，结论=硬件）

### 9.1 现象
带载/高调制时，三相电流偶发被污染成真实值的 2~3 倍（实测 `Ic` 原始 2.83A @ 真实 1.0A），
表现为力矩脉动、`Iq` 尖刺；而 **ADC 所有硬件告警（触发冲突/DMA FIFO/AHB 错）全程为 0**。

### 9.2 定位过程（三条独立证据）
1. **通道顺序**：`Ia`(队列第1)→`Ib`(第2)→`Ic`(第3) 依次变脏 ⇒ 与"采样时刻越晚"强相关
2. **零点正常**：停止段三相和仅 0.06A ⇒ 排除失调/换算
3. **非 ADC 故障**：告警位全 0、`adc_bad`≈0 ⇒ ADC 转换本身是对的，采到的是**开关振铃**那一瞬

### 9.3 试过但无效的软件办法
| 办法 | 结果 |
|---|---|
| 缩短采样时间 20→10 周期 | 原始更差（更靠近开关沿） |
| 队列 4→3 路（去掉 Ibus） | 无本质改善 |
| 读结果寄存器（BUS_MODE_EN） | ❌ 会把 ADC 变成"读一次转一次"，采样脱离 PWM 同步，波形削顶（已废弃） |
| 参考 08 工程：`adc16_enable_motor()` (MOTO_EN) + `sample_cycle=20` + `sel_sync_ahb=false` | ❌ 无改善（MOTO_EN 只管转换启动同步；08 那块板模拟前端有 RC，所以看不到这问题） |

### 9.4 采样配置（后续已修订，当前值以此为准）
本节的采样配置在后续的 ADC 修复中又改过，**当前代码**为：
- **ADC0**：单实例、PMT 3 通道队列 `{Ia,Ib,Ic}`、PWM(`TRGO_0`→`ADCX_PTRGI0A`/`TRG0A`) 触发、
  16bit、`adc_ahb_en=true`、`sample_cycle=10`、`sel_sync_ahb=true`、无 `adc16_enable_motor()`、
  DMA 到 `adc_dma_buf`（`.noncacheable.bss`，192 字节）。
  > 早年这里记的 `sample_cycle=20`、`sel_sync_ahb=false`、`adc16_enable_motor()` 已作废。
- **控制侧坏点修复**：早期版本在 `FOC_current()` 里做过 `|Δi|` 判据修复（计数 `fix_cnt`），
  **当前代码已移除**；现在只做 DMA 帧元数据校验。坏点修复留到硬件加 RC 后重新评估。
  ⚠️ 不要用"占空比窗口"猜坏相（会选错相并把坏值扩散，实测更差）。
- 诊断：`isum`（三相和，恒应≈0）保留；`isum_cnt` / `fix_cnt` / `cflt_*` 已不在 VOFA 输出。
- 效果（历史记录）：原始 `Ic` 1.46A → 进环 `Iq` 0.33A，修复率约 4.6%。

### 9.5 根治办法（下一版硬件必须做）
**三个电流运放输出加 RC：100Ω + 1nF（τ≈100ns）**，开关振铃直接滤掉。
加了之后本节所述的坏点问题基本消失，软件无需再做坏点修复，只需保留帧校验。
