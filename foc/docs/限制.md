# 限制与约束

本文件记录本项目的**硬性限制**，改代码前先看这里。

## 1. 硬件限制

1. **无过流报警输入**。原理图全图搜索 `FAULT` / `ITRIP` / `OCP` / `ALERT` / `比较器` = 0 命中；栅极驱动 U2 只有 HIN/LIN 输入，没有故障输出引脚。
   → PWM 的异步/同步故障保护**目前无法使用**（缺信号源）。
   → 过流只能靠软件保护：ADC 采电流 + 程序判断 + 关输出（响应慢，防不了直通/短路）。

2. **低边分流采样**（5 mΩ，在三个下桥）。采样必须在"三相下桥全开"的时刻做，即计数 ≈ 0。

3. 栅极驱动极性未确认。若下桥驱动为**低有效**，则：
   - 故障输出应改为 `pwm_fault_output_1`
   - 需要打开 `pwmv2_enable_output_invert()`（下桥三路）

## 2. 数值约束（必须满足）

1. **死区 ≥ 2 个计数时钟**。手册规定 `DEAD_AREA` < 2 会被硬件视为**无死区**。当前 500 ns = 100 tick。

2. **占空比上限**（受死区限制，中心对齐）：

   ```
   (T − d)/2 必须大于死区  →  duty ≤ 1 − 2×dead/T
   当前：1 − 2×100/10000 = 0.98
   ```

3. **占空比下限**（受最小导通脉宽限制）：`PWM_MIN_ON_NS = 1000 ns` = 200 tick → `duty_min = 0.02`。
   由 `PWM_MIN_ON_NS` 宏控制，按栅极驱动/开关管要求调整。

4. **采样窗口约束（低边分流必看）**：

   ```
   计数≈0 处下桥导通窗口 = (T − d)/2 − 死区
   占空比 0.98 时：(10000−9800)/2 − 100 = 2 tick ≈ 10 ns   ← 完全不够 ADC 采样
   要求窗口 ≥ ADC 转换时间(按 500 ns = 100 tick 计)：
        duty ≤ 1 − 2×(100+100)/10000 = 0.96
   ```

   ⚠ `pwm_get_duty_max()` 目前只扣了死区（返回 0.98），**未扣采样窗口**。做低边电流采样时，实际占空比上限要压到 0.96 以下。

## 3. 配置规则（必须遵守）

1. **互补模式必须成对配置**：通道 (0,1)、(2,3)、(4,5) 各写一次，共 6 次；只写一路结果未知。

2. **死区必须 6 路都配**。即使开了互补模式，死区寄存器仍是每路独立的。

3. **三相必须同步启动**：用 `pwmv2_reset/enable/start_multi_counter_sync(PWM, 0x07)`，不能逐个启动（否则三相互差相位）。

4. **burst 必须关**：使用 `CNT_SW_START` 启动时 burst 计数生效，`CNT_BURST = 0` 时只发 1 个周期。

5. **改影子值必须 unlock → 写 → lock**，三步一个不能少。

6. **影子寄存器锁定功能要在 `pwmv2_deinit()` 之后重新打开**（`pwmv2_enable_shadow_lock_feature()`），否则 lock 无效。

7. **PWM 重载中断与 ADC 中断二选一**，两个都开会导致一个 PWM 周期进两次中断、FOC 跑两遍。

8. **接线顺序必须为 U上/U下/V上/V下/W上/W下**，与通道 (0,1)(2,3)(4,5) 对应。已验证与原理图一致。

9. **占空比只在 PWM 周期中断里更新**。从主循环随机时刻调用，有概率卡在锁存瞬间，导致某一相该周期 a/b 不配对。

## 4. 代码约定

1. 不使用 `board.h`；板级宏定义在 `core/inc/tim.h`。
2. `printf` 走 SEGGER RTT；**中断服务函数里禁止使用** `printf`。
3. 注释格式与写法见 `注释规范.md`。

## 5. 已知状态与风险

1. **上电初始状态**：影子值全 = reload → 占空比 0% → **上管全关、下管全开**（三相下桥常开）。
   不接电机、不上母线时无风险；接电机且母线带电时，电机会被短路制动。
2. **当前无任何过流保护**（硬件没有、软件还没写）。接电机前必须先做软件过流保护。
3. `pwm_init()` 目前是引脚复用 + 外设初始化的完整配置，但**没有占空比更新入口**，所以引脚只会输出静态电平，不会发波。
