# 限制与约束

本文件记录本项目的**硬性限制**，改代码前先看这里。

## 1. 硬件限制

1. **无过流报警输入**。原理图全图搜索 `FAULT` / `ITRIP` / `OCP` / `ALERT` / `比较器` = 0 命中；栅极驱动 U2 只有 HIN/LIN 输入，没有故障输出引脚。
   → PWM 的异步/同步故障保护**目前无法使用**（缺信号源）。
   → 过流只能靠软件保护：ADC 采电流 + 程序判断 + 关输出（响应慢，防不了直通/短路）。

2. **低边分流采样**（5 mΩ，在三个下桥）。采样必须在"三相下桥全开"的时刻做，即计数 ≈ 0。

3. 栅极驱动极性未确认。若下桥驱动为**低有效**，则：
   - 故障输出应改为 `pwm_fault_output_1`
   - 需要打开 `pwmv2_enable_output_invert()`（下桥三路）

## 2. 数值约束（必须满足）

1. **死区 ≥ 2 个计数时钟**。手册规定 `DEAD_AREA` < 2 会被硬件视为**无死区**。当前 `PWM_DEAD_TIME_NS = 0 ns`（软件死区清零，依赖 FD6288 自带 100 ns 硬件互锁）。

2. **占空比上限**（受死区限制，中心对齐）：

   ```
   (T − d)/2 必须大于死区  →  duty ≤ 1 − 2×dead/T
   当前：1 − 2×2/5000 = 0.9992（pwm_get_duty_max() 取 1−(2·dead+4)/(reload+1)）
   ```

3. **占空比下限**（受最小导通脉宽限制）：`PWM_MIN_ON_NS = 1000 ns` = 200 tick → `duty_min = 200/5000 = 0.04`。
   由 `PWM_MIN_ON_NS` 宏控制，按栅极驱动/开关管要求调整。

4. **采样窗口约束（低边分流必看）**：

   ```
   计数≈0 处下桥导通窗口 = (T − d)/2 − 死区        (T = reload+1 = 5000 @ 40kHz)
   占空比 0.98 时：(5000−4900)/2 − 2 = 48 tick ≈ 240 ns   ← 不够 ADC 采样
   要求窗口 ≥ ADC 转换时间(按 500 ns = 100 tick 计)：
        (1−D)·2500 − 2 ≥ 100  →  duty ≤ 0.9592
   ```

   ⚠ `pwm_get_duty_max()` 只扣死区（≈1.0），**未扣采样窗口**。`pwm_set_duty()` 里用
   `PWM_DUTY_MAX_LIMIT = 0.96` 单独钳位；做低边电流采样时上限必须保持 0.96 或更低。

## 3. 配置规则（必须遵守）

1. **互补模式必须成对配置**：通道 (0,1)、(2,3)、(4,5) 各写一次，共 6 次；只写一路结果未知。

2. **死区必须 6 路都配**。即使开了互补模式，死区寄存器仍是每路独立的。

3. **三相必须同步启动**：用 `pwmv2_reset/enable/start_multi_counter_sync(PWM, 0x07)`，不能逐个启动（否则三相互差相位）。

4. **burst 必须关**：使用 `CNT_SW_START` 启动时 burst 计数生效，`CNT_BURST = 0` 时只发 1 个周期。

5. **改影子值必须 unlock → 写 → lock**，三步一个不能少。

6. **影子寄存器锁定功能要在 `pwmv2_deinit()` 之后重新打开**（`pwmv2_enable_shadow_lock_feature()`），否则 lock 无效。

7. **PWM 重载中断与 ADC 中断二选一**，两个都开会导致一个 PWM 周期进两次中断、FOC 跑两遍。

8. **接线顺序必须为 U上/U下/V上/V下/W上/W下**，与通道 (0,1)(2,3)(4,5) 对应。已验证与原理图一致。

9. **占空比只在 PWM 周期中断里更新**。从主循环随机时刻调用，有概率卡在锁存瞬间，导致某一相该周期 a/b 不配对。

## 4. 代码约定

1. 不使用 `board.h`；板级宏定义在 `core/inc/tim.h`。
2. `printf` 走非阻塞环形缓冲日志（`log.c`），由最低优先级 log 任务搬到 UART0 PA00/PA01（SES 构建）。**中断服务函数里不建议 printf**（格式化本身耗时，仍建议避免）。
3. 注释格式与写法见 `注释规范.md`。

## 5. 已知状态与风险

1. **上电初始状态**：影子值全 = reload → 占空比 0% → **上管全关、下管全开**（三相下桥常开）。
   不接电机、不上母线时无风险；接电机且母线带电时，电机会被短路制动。
2. **软件过流保护已实现**：40 kHz ADC 中断里有硬限幅（`foc.c: foc_adc_callback`），
   5 kHz FOC 任务里有软保护（`foc_task.c: foc_protection_check`）。
   硬件仍无过流引脚，直通/桥臂短路无法靠软件防住。
3. `pwm_init()` 是引脚复用 + 外设初始化；占空比更新入口为 **`pwm_set_duty(du, dv, dw)`**（写影子寄存器 1~6，周期边界生效），已实现。
4. **失能路径**（`disable_bldc_pwm_output`）把 6 路强制为电平 1，是否等于"六管全关"
   取决于 FD6288 极性与 PWMv2 pair 模式行为，**尚待示波器确认**（见 `docs/CODE_STYLE.md`）。

5. **电流环的死区补偿必须用"给定 dq 电流"前馈，不能用实测相电流**。用实测值是一
   条正反馈支路，增量增益 = `Vbus·(DT_DEAD_NS/T_pwm)/DT_COMP_ITH` ≈ 24V×0.4%/0.8A
   = **0.12 V/A**（等效给绕组串了 −0.12Ω）：
   - 4310（R=8.29Ω）：无影响；2312（R=0.144Ω）：临界；**5210（R=0.042Ω）：等效 −0.078Ω**
   - 现象：5210 一进电流闭环（0x27 的 `dir_pp` 保持段，iq≈0.6A）就自激，一拍打到电压轨，
     25µs 内冲上 12A，触发 `FAULT 6 相过流硬限幅`
   - 历史：`5ed4143` 里这一行是 `// foc_deadtime_comp();`（注释掉的，5210 标定正常）；
     `71a1913`「wip: 电流环重新启用死区补偿」把它改成生效 → 5210 标定从此必炸。
     现在（`foc_current`）已改为**按给定 dq 电流反算三相方向的前馈补偿**，无反馈、不会自激。
6. **5210 上任何 0.1 V 的电压误差就是 2.4 A 电流误差**（0.1V / 0.042Ω）。死区畸变
   ≈0.115 V（由 L 探测两点解出：`(0.3−Vl)/(0.2−Vl)=1.690/0.776` → Vl≈0.115 V），
   等于 **2.7 A**。所以 5210 的强托波形上会看到与基波同量级的低频成串振荡（约 600 Hz、
   每个电周期一次）；补偿没做好/没做完时这是**必然**现象，不是新故障。
   `0x27` 的 `res:` 行现在会打印 `Voff = ures − I·R`，**这个值越接近 0 说明死区补偿越准**
   （补偿没生效时约 0.25 V；注意该点也受转子晃动/反电势污染）。

7. **电流环带宽 / L 注入频率 / 实际交叉频率三者的关系（5210 踩过）**。
   5210 电气极点 `R/(2πL) = 0.042/(2π·10µH) ≈ 670 Hz`，而 `L` 标定值会**偏大 2~3 倍**
   （注入电压被死区吃掉 → 电流偏小 → Z 偏大 → L 偏大）。因为 `Kp = L_meas·ωc`，
   实际交叉频率 `= ωc·L_meas/L_real`。2026-11-16 实测：`bw=1000Hz` 时环路在 **2.5kHz
   自激**（Id ±0.85A、Iq 3±1.4A，幅值只受死区非线性限制，峰值撞 12A 过流；电压从不饱和、
   均值 Iq 仍是准的 3.000A）。处置：
   - `Config.current_ctrl_bw` 5210 档改 **300Hz**（实际交叉落到 ~800Hz）；
   - **L 注入频率已与带宽解耦**，固定 `CALIB_L_INJ_HZ = 1kHz`（否则降带宽会把注入频率
     一起降下去，Z/R→1，L 更测不准）；
   - 用完 `0x58` 现场扫带宽验证：把 bw 从 1000 往下扫，振荡消失的那个点就是当前的真实裕度。
   等 L 标定修准（前馈补偿把死区吃掉）后，带宽可以再往 800~1000Hz 调。
