# 项目描述

## 1. 概况

| 项 | 内容 |
|---|---|
| 项目 | FOC 电机控制 + EtherCAT 从站 |
| 工程路径 | `D:\Desktop\FOC\foc\` |
| 芯片 | HPM5E31（HPM5E00 系列，RISC-V） |
| 硬件 | 自制板「FOC+EtherCAT」V1.0，原理图 `D:\Desktop\HPM5E3Y原理图.pdf`（3 页：HPM_Core / 驱动 / 电源） |
| 开发环境 | SEGGER Embedded Studio，工程文件 `hpm5e00evk_flash_xip_debug\segger_embedded_studio\foc.emProject` |
| SDK | `hpm_sdk_localized_for_hpm5e00evk`（随工程存放，未依赖系统安装版） |
| 控制对象 | 三相 BLDC/PMSM，三相互补 PWM 驱动 |

## 2. 时钟（实测，上电打印）

| 时钟 | 频率 |
|---|---|
| CPU0 | 480 MHz |
| AHB | 200 MHz |
| AXIF / AXIS / AXIC | 200 MHz |
| XPI0 | 100 MHz |
| MCHTMR0 | 24 MHz |

**PWM 计数时钟 = AHB = 200 MHz**（PWM0 属于 AHB 时钟组）

## 3. 硬件资源

### 3.1 PWM 六路输出（与原理图核对一致）

| 引脚 | MCU 复用 | 原理图标注 | 用途 | PWM 通道 |
|---|---|---|---|---|
| PD00 | PWM0_P_0 | PWM1_H | U 相上管 | ch0 |
| PD01 | PWM0_P_1 | PWM1_L | U 相下管 | ch1 |
| PD02 | PWM0_P_2 | PWM2_H | V 相上管 | ch2 |
| PD03 | PWM0_P_3 | PWM2_L | V 相下管 | ch3 |
| PD04 | PWM0_P_4 | PWM3_H | W 相上管 | ch4 |
| PD05 | PWM0_P_5 | PWM3_L | W 相下管 | ch5 |

### 3.2 电流采样

| 信号 | 说明 |
|---|---|
| M0_U_IN± / M0_V_IN± / M0_W_IN± | 三相低边分流电阻 **5 mΩ** |
| M0_IBUS± | 母线电流 |
| VREF1V65 | 1.65 V 偏置（双向采样） |

### 3.3 栅极驱动

- U2：20 脚三相栅极驱动，输入 `M0_HIN1~3` / `M0_LIN1~3`，输出 `M0_HO/LO1~3`
- **无故障输出引脚**（详见 `限制.md`）

### 3.4 通信与电源

- EtherCAT：2 路 PHY + 2 个 RJ45（HR911105A）
- 电源：DCBUS(VBUS) → 12V → 5V → 3.3V，含防反接/防过压/缓启动

## 5. PWM 配置（`core/src/tim.c`，参数已实测）

| 项 | 值 |
|---|---|
| 外设 | PWM0 |
| 载波频率 | 20.00 kHz（reload = 9999，周期 = 10000 个 200 MHz 时钟） |
| 输出模式 | 互补（PAIR_MODE）+ 硬件死区 + 两点模式 |
| 波形 | 中心对齐（后续占空比函数按 a=(T−d)/2、b=(T+d)/2 写） |
| 死区 | 100 tick = 500 ns |
| 占空比范围 | [0.020, 0.980]（`pwm_get_duty_min/max()`；上限未计采样窗口，见 `限制.md`） |
| 计数器 | CNT0/CNT1/CNT2 同步启动（`*_multi_counter_sync(PWM, 0x07)`） |
| 影子值分配 | 0=周期（三相共用）、1/2=U相 a/b、3/4=V相 a/b、5/6=W相 a/b、9=预留 ADC 采样点 |
| 比较器分配 | CMP0/1=U相、CMP4/5=V相、CMP8/9=W相、CMP20=预留 ADC 触发（计数=1） |
| 更新时机 | 周期值与比较值均为 `on_reload`（周期边界统一生效） |
| 故障保护 | 仅配置了故障输出状态（输出 0）+ 调试暂停自动关断；**无外部故障输入** |
