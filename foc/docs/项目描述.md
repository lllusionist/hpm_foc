## 3. 硬件资源

### 3.1 PWM 六路输出（与原理图核对一致）

| 引脚 | MCU 复用 | 原理图标注 | 用途 | PWM 通道 |
|---|---|---|---|---|
| PD00 | PWM0_P_0 | PWM1_H | U 相上管 | ch0 |
| PD01 | PWM0_P_1 | PWM1_L | U 相下管 | ch1 |
| PD02 | PWM0_P_2 | PWM2_H | V 相上管 | ch2 |
| PD03 | PWM0_P_3 | PWM2_L | V 相下管 | ch3 |
| PD04 | PWM0_P_4 | PWM3_H | W 相上管 | ch4 |
| PD05 | PWM0_P_5 | PWM3_L | W 相下管 | ch5 |

### 3.2 模拟采样与 ADC 通道分配

| 信号 | MCU 引脚 | ADC 通道 | 来源 |
|---|---|---|---|
| IA（A 相电流） | PF27 | **ADC0_IN0** | 低边 5 mΩ |
| IB（B 相电流） | PF26 | **ADC0_IN1** | 低边 5 mΩ |
| IC（C 相电流） | PF21 | **ADC0_IN2** | 低边 5 mΩ |
| IBUS（母线电流） | PF20 | ADC0_IN3 | 母线 5 mΩ |
| NTC（温度） | PF24 | ADC1_IN10 | — |
| VA / VB / VC | PF16 / PF18 / PF19 | ADC1_IN8 / IN11 / IN13 | 分压 + 中性点 |

`VREF1V65` = 1.65 V 偏置（双向采样，零电流 ≈ 码值 32768）

### 3.3 栅极驱动

- U2：20 脚三相栅极驱动，输入 `M0_HIN1~3` / `M0_LIN1~3`，输出 `M0_HO/LO1~3`
- **无故障输出引脚**（详见 `限制.md`）

### 3.4 通信与电源

- EtherCAT：2 路 PHY + 2 个 RJ45（HR911105A）
- 电源：DCBUS(VBUS) → 12V → 5V → 3.3V，含防反接/防过压/缓启动

## 5. PWM 配置（`core/src/tim.c`，参数已实测）

| 项 | 值 |
|---|---|
| 外设 | PWM0 |
| 载波频率 | 20.00 kHz（reload = 9999，周期 = 10000 个 200 MHz 时钟） |
| 输出模式 | 互补（PAIR_MODE）+ 硬件死区 + 两点模式 |
| 波形 | 中心对齐（占空比函数按 a=(T−d)/2、b=(T+d)/2 写） |
| 死区 | 100 tick = 500 ns |
| 占空比范围 | [0.020, 0.980]（`pwm_get_duty_min/max()`；上限未计采样窗口，见 `限制.md`） |
| 计数器 | CNT0/CNT1/CNT2 同步启动（`*_multi_counter_sync(PWM, 0x07)`） |
| 影子值分配 | 0=周期（三相共用）、1/2=U相 a/b、3/4=V相 a/b、5/6=W相 a/b、**7=ADC 采样点** |
| 比较器分配 | CMP0/1=U相、CMP4/5=V相、CMP8/9=W相、**CMP20=ADC 触发** |
| 更新时机 | 周期值与比较值均为 `on_reload`（周期边界统一生效） |
| 故障保护 | 仅配置故障输出状态（输出 0）+ 调试暂停自动关断；**无外部故障输入** |

## 6. ADC 配置（`core/src/adc.c`，已上板实测）

| 项 | 值 |
|---|---|
| 外设 / 中断 | ADC0 / `IRQn_ADC0`，PLIC 优先级 1 |
| 时钟 | `clock_adc0`，源 = AHB(200 MHz)，分频 4 → **50 MHz** |
| 模式 | 抢占（PMT / 注入），16 位，采样时间 20 个 ADC 时钟 |
| 队列 | IA / IB / IC 三通道，**只在最后一个通道开中断** |
| 触发链 | PWM CMP20（计数=1）→ TRGO_0 → TRGM → `ADCx_PTRGI0A`(TRG0A) |
| 结果读取 | **不用 DMA**：读 `PRD_RESULT[ch]`（`adc16_get_prd_result()`） |
| `adc_ahb_en` | `false`（关掉 ADC 内置 DMA，避免往地址 0 写） |
| 数据出口 | 全局 `volatile foc_data_t FOC`（成员 `Ia/Ib/Ic/Va/Vb/Vc`，**当前存原始码值**） |
| 实测结果 | 中断 20 kHz（cnt 每 100 ms +2000）；零点 IA≈33055 / IB≈33290 / IC≈33160 |

## 8. 遗留问题

| # | 问题 | 影响 |
|---|---|---|
| 1 | 板子**无过流报警输入** | 无法使用 PWM 硬件故障保护，只能软件保护（见 `限制.md`） |
| 2 | `pwm_get_duty_max()` 未计 ADC 采样窗口 | 低边采样时实际占空比上限应压到 0.96（见 `限制.md`） |
| 3 | `compile_commands.json` 会随 CMake 配置过时 | VS Code 若改用它需重新 configure |
| 4 | 仓库根 `board\hpm5e00evk\` 与 SDK 内板级文件重复 | 工程当前引用 SDK 内那份，根目录那份用途待确认 |
