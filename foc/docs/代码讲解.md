## 1. 全局鸟瞰：任务、中断、数据流

### 1.1 分层

| 层 | 频率 | 入口 | 职责 |
|---|---|---|---|
| **ADC 中断** | **20 kHz** | `isr_adc()` → `foc_adc_callback()` | 采三相电流、跑**电流环**、输出 SVPWM 占空比、VOFA 采样 |
| **FOC 任务** | **5 kHz** | `Task_FOC()` → `CONTROLLER_loop()` | 外环：电流斜坡 / 速度环 / 位置环、摩擦与齿槽前馈、限幅 |
| **慢任务**（同任务每 5 拍） | **1 kHz** | `foc_update_voltages()`、`calibration_loop()`、`anticogging_loop()` | 相电压/母线采集、标定、齿槽标定、保护检测 |
| **编码器任务** | **5 kHz** | `Encoder_task()` → `ENCODER_loop()` | SPI 读 MT6835、PLL 算角度/转速 |
| **VOFA 发送** | 5 kHz 采样 / ~1 kHz 打包 | `vofa_push_sample()` / `vofa_task` | 22 通道波形上传 |
| FreeRTOS tick | 10 kHz | — | `vTaskDelayUntil(&last, 2)` = 0.2 ms |

### 1.2 一次控制的数据流

```
             ┌──────────── 20 kHz（ADC 中断，优先级最高）────────────┐
 MT6835 ──►  编码器任务(5kHz) ──►  encoder.phase / encoder.vel        │
                                        │                             │
 PWM0 TRGO_0 ──► ADC0 注入队列(Ia,Ib,Ic) ──► isr_adc()                │
                                        │                             │
                                        ▼                             │
                              foc_adc_callback()                      │
                                        │                             │
                              FOC_current(Id_set=0, Iq_set, phase)    │
                                 │ Clarke → Park → PI → 解耦/前馈      │
                                 │ → 电压归一化 → SVPWM → 死区补偿     │
                                 ▼                                    │
                              pwm_set_duty() ──► 影子寄存器(下个周期生效)
                                                                      │
             └──────────── 5 kHz（Task_FOC，中优先级）───────────────┘
                              CONTROLLER_loop()
                                 读 encoder.vel / count_aligned
                                 算 FOC.Iq_set（速度PI + 前馈）
```

**关键理解**：外环（5 kHz）只负责**算出一个电流指令 `FOC.Iq_set`**；
真正的电流环在 20 kHz 中断里跑，两者通过 `FOC.Iq_set` 这个全局变量耦合。

## 2. 启动流程

```
main()
 ├─ board_init / clock / uart / pinmux
 ├─ foc_init()            // 参数、ADC、电流环增益、ADC 中点校准
 ├─ ENCODER_init()        // SPI1 + DMA
 ├─ config_init()         // 从 Flash 读配置（CRC 校验失败则用默认值）
 ├─ USB 初始化、VOFA 初始化
 └─ 创建任务：Task_FOC(5kHz) / Encoder_task(5kHz) / vofa_task / usb_task
     └─ vTaskStartScheduler()
            │
            ▼
       FSM: BOOT_UP ──► IDLE ──(使能)──► RUN
                            ├─(0x27)──► CALIBRATION
                            └─(0x28/0x2E)──► ANTICOGGING
```

**`foc_init()` 里最容易被忽略的两件事**：

```c
if (Config.current_gain_magic == CONFIG_MAGIC && ...) {   // Flash 里有有效增益
	FOC.current_ctrl_p_gain = Config.current_kp;      // 直接用存下来的
	FOC.current_ctrl_i_gain = Config.current_ki;
} else {
	FOC_update_current_ctrl_gain(Config.current_ctrl_bw);  // 按带宽现算
}
adc1_init();
if (!foc_adc_midpoint())          // 上电必须标一次电流/电压零点
	FOC.fault_code = FOC_FAULT_ADC;
```

> ⚠️ `#define VBUS_DEFAULT 12.0f` 是"还没采到母线电压"时的占位值（现在是 24 V 系统），
> 只影响 `foc_init` 到第一次 `foc_update_voltages()` 之间的极短时间。

## 3. PWM 定时器 `tim.c`

### 3.1 作用与逻辑

- PWM0 三对互补通道（PD00~PD05），载波 **20 kHz**，计数模式为**递增**，占空比靠比较点放置。
- 六路占空比不是"从 0 到 duty 的高电平"，而是**高电平居中**（两点模式：开点 `half-h`、
  关点 `half+h`）——这样每个周期的**计数起点附近三相下管都导通**，正好用来采低边分流电阻。
- 影子寄存器配成 **reload 时刻统一生效**：中断里算出的占空比要等到下一个周期开始才真正改变，
  这带来约 **1 个 PWM 周期的延迟**（电流环设计要算进去）。
- **ADC 触发**：比较点 20 的值设为 1，把 `TRGO_0` 经 TRGM 直通给 `ADC0 PTRGI0A`
  → 三相电流在**计数起点（谷点）**被硬件触发采样，避开开关沿。

### 3.2 逐行讲解：`pwm_init()`

```c
g_pwm_clk_hz = clock_get_frequency(clock_pwm0);          // 取 PWM 时钟（计数频率）
g_dead_ticks = pwm_dead_ns_to_ticks(PWM_DEAD_TIME_NS);   // 死区换算成计数（本板=0，靠 FD6288 硬件 100ns）
reload = g_pwm_clk_hz / PWM_FREQ_HZ - 1;                 // 周期=(reload+1)个时钟
if ((g_pwm_clk_hz == 0U) || (reload <= (4U * g_dead_ticks)))
	printf("pwm_init: clock/dead-time config invalid!\n");  // 参数不合理只报警，不阻塞
```

| 行 | 作用 |
|---|---|
| `HPM_IOC->PAD[IOC_PAD_PDxx].FUNC_CTL = ...PWM0_P_x` | 六个引脚复用成 PWM 输出 |
| `pwmv2_deinit(PWM)` | 复位 PWM 外设，从干净状态配置 |
| `pwmv2_enable_shadow_lock_feature()` | 打开影子寄存器锁，防止异步写坏 |
| `pwmv2_set_shadow_val(..., INDEX(0), reload, ...)` | 影子 0 = 周期值，三相共用一个计数器周期 |
| `INDEX(1)..INDEX(6)` | 三对通道的开点/关点（U/V/W 各两个） |
| `INDEX(7) = 1` + `CMP_INDEX(20)` + `set_trigout_cmp_index(PWM,0,...)` | 比较点 20 在计数=1 时翻转触发输出 0，即"周期起点触发" |
| `pwmv2_cmp_update_trig_time(..., on_reload)` | 比较点也在 reload 时统一生效（避免半周期改占空比产生毛刺） |
| `pwmv2_counter_select_data_offset_from_shadow_value()` | 三个计数器的周期都取自影子 0 |
| `CMP_INDEX(0/1)` ← 影子 1/2 | U 相开/关点；V 相用比较点 4/5，W 相 8/9（硬件绑定，不能乱选） |
| `pwmv2_counter_burst_disable()` | 关 burst，否则只发一个周期就停 |
| `pwmv2_enable_pair_mode()` | 六路配成三对互补输出 |
| `pwmv2_set_dead_area()` | 硬件死区（本板 0 tick，实际死区由驱动芯片保证） |
| `pwmv2_disable_four_cmp()` | 用"两点模式"（每通道 2 个比较点）而不是四点模式 |
| `pwm_fault_config()` | 硬件故障保护（需要软件清除后恢复） |
| `pwmv2_channel_enable_output()` ×6 | 使能六路输出 |
| `pwmv2_reset/enable_multi_counter_sync` + `start_pwm_output_sync` | 三个计数器同步启动，否则三相不同步 |

### 3.3 逐行讲解：`pwm_set_duty()`

```c
if (du > PWM_DUTY_MAX_LIMIT) du = PWM_DUTY_MAX_LIMIT;   // 0.96 上限：给低边采样留最小窗口
uint32_t half = reload >> 1;                            // 周期中点
uint32_t hu = (uint32_t)(du * (float)reload) >> 1;      // 导通宽度的一半
pwmv2_set_shadow_val(PWM, INDEX(1), half - hu, ...);    // U 相开点（中点前半宽处）
pwmv2_set_shadow_val(PWM, INDEX(2), half + hu, ...);    // U 相关点（中点后半宽处）
```

| 行 | 作用 |
|---|---|
| `PWM_DUTY_MAX_LIMIT = 0.96` | 占空比上限。留 4% 窗口给低边分流采样（否则下管导通时间太短，采不到电流） |
| `half = reload >> 1` | 半周期。所有开/关点都以它为中心对称放置 |
| `hu = du*reload/2` | 高电平持续 `du*周期`，所以半宽 = `du*reload/2` |
| `half - hu` / `half + hu` | 高电平被"居中"放在周期中间。计数起点（=ADC 触发点）时三相全在下管导通区 |
| `shadow_register_unlock/lock` | 写影子寄存器前后必须解锁/上锁 |

> **为什么高电平居中**：低边分流采样要求"三相下桥同时导通"，
> 而这个时刻就是高电平之外的时间；高电平居中后，周期起点必然落在下桥导通区。

## 4. ADC 采样 `adc.c`

### 4.1 作用与逻辑

两个 ADC 分工：

| ADC | 触发 | 内容 | 频率 |
|---|---|---|---|
| **ADC0** | PWM0 `TRGO_0`（硬件） | Ia / Ib / Ic（3 路抢占队列 + DMA） | **20 kHz** |
| **ADC1** | 软件触发（`TRG0B` / `TRG0C`） | VA/VB/VC/VBUS、IBUS | **1 kHz** |

ADC 时钟 = AHB(200 MHz)/4 = 50 MHz，16 bit，采样保持 10 个周期（原来 20，缩短是为了让整队转换
更早结束，避免最后一路 Ic 撞上开关沿）。

### 4.2 逐行讲解：`isr_adc()`（20 kHz 中断）

```c
uint32_t st = adc16_get_status_flags(HPM_ADC0);            // 读中断状态
uint32_t complete = HPM_ADC0->TRG_CMPT_FLAG;               // 读"队列完成"标志
adc16_clear_status_flags(HPM_ADC0, st);                    // 清中断状态（否则会反复进中断）
if (complete & (1U << ADC_TRIG_CH))
	HPM_ADC0->TRG_CMPT_FLAG = (1U << ADC_TRIG_CH);     // 清 TRG0A 的完成标志
```

| 行 | 作用 |
|---|---|
| `bool valid = !(st & ADC_PMT_ERROR_MASK) && (complete & ...)` | 没有任何 ADC 错误，且本队列确实完成 |
| 循环校验 `trig_ch / seq_num / adc_ch` | 逐通道核对 DMA 数据确实属于本次触发、顺序、通道号都对（防错位） |
| `if (!valid) { bad_current_frames++; FOC.adc_current_missed++; return; }` | 坏帧直接丢弃并计数，交给保护逻辑 |
| `FOC.Ia/Ib/Ic = adc_dma_buf[i].result` | 搬进全局，供电流环和波形使用（原始 ADC 码值，**还没换算成 A**） |
| `FOC.isum = ((Ia-mid_a)+(Ib-mid_b)+(Ic-mid_c)) * SCALE` | 三相电流和，理论恒为 0，用来判断 Ic 采样是否被开关沿污染 |
| `if (adc_ready && |isum|>0.1) { Ic = mid_c - (Ia-mid_a) - (Ib-mid_b); }` | Ic 坏样本用 `Ic = -(Ia+Ib)` 重建（限幅到 0~65535） |
| `current_snapshot_seq++ ; ... ; current_snapshot_seq++` | 用"序列号自增"做简单读写锁，让 1 kHz 任务能安全取到一致的三相快照 |
| `if (adc_callback) adc_callback();` | 调用注册的回调 → `foc_adc_callback()`（电流环入口） |

### 4.3 ADC1 的线性电压采集

`adc1_read_all()` / `adc1_read_ibus()` 是**软件触发 + 轮询等待**，
不占用 20 kHz 中断；1 kHz 任务里调用，读到后由 `foc_update_voltages()` 换算成伏特并滤波。

## 5. 实时控制核心 `foc.c`

### 5.1 作用与逻辑

这个文件是整个控制的"心脏"：

| 函数 | 作用 |
|---|---|
| `foc_adc_callback()` | 20 kHz 中断主体：采样分频、模式分发、调用电流环 |
| `FOC_current()` | **电流环**：Clarke→Park→PI→解耦/前馈→饱和→逆 Park→SVPWM→死区补偿→占空比 |
| `FOC_voltage()` | **开环电压输出**（标定用，旁路电流环） |
| `foc_deadtime_comp()` | 死区补偿：按相电流方向给占空比加减固定量 |
| `FOC_update_current_ctrl_gain()` | 由带宽算 `kp=L·ωc`、`ki=R·ωc` |
| `foc_arm()` / `foc_disarm()` | 使能/失能：清零积分、PWM 强制输出/恢复 |
| `foc_adc_midpoint()` | 上电标定电流与电压零点（各 32 次平均） |
| `foc_update_voltages()` | 1 kHz 换算三相电压、母线电压、母线电流 |

### 5.2 逐行讲解：`foc_adc_callback()`（20 kHz 入口）

```c
static uint8_t vofa_div = 0;
if (++vofa_div >= VOFA_SAMPLE_DECIM) {      // 20kHz / 4 = 5kHz 波形采样
	vofa_div = 0;
	vofa_push_sample();                 // 取一份快照进环形缓冲（发送在任务里）
}
if (!FOC.is_armed) return;                  // 没使能：只发波形，不控制
```

| 行 | 作用 |
|---|---|
| `if (FOC.calib_vinj_mode)` 分支 | **电感标定**：α 轴注入正弦电压，同时用 `sin/cos` 解调累加 Ia（锁相检测阻抗） |
| `if (FOC.calib_mode)` 分支 | **其它标定**：用标定状态机下发的角度/电流跑电流环（角度不用编码器） |
| `if (stage != RUN && stage != ANTICOGGING) return;` | 只有运行态才做正常闭环（标定态已在上面的分支提前返回） |
| `if (FOC.openloop_voltage > 0)` | 调试用：直接用固定电压矢量，旁路电流环 |
| `iq_set = CLAMP(FOC.Iq_set, ±current_limit)` | 外环给的电流指令再做一次硬限幅（安全兜底） |
| `phase = encoder.phase + FOC.phase_offset` | 电角度取编码器（`phase_offset` 是调试偏移，正常为 0） |
| `FOC_current(FOC.Id_set, iq_set, phase, encoder.phase_vel)` | 进入电流环 |

> ⚠️ 这里的注释 `"40kHz 8 分频 -> 5kHz"` 是**过时的**（实际 ISR 20 kHz、4 分频），
> 但代码行为是对的（`VOFA_SAMPLE_DECIM = 4`）。

### 5.3 逐行讲解：`FOC_current()`（电流环，最关键的函数）

```c
/* ① ADC 码值 → 安培（减零点、乘标度） */
float ia = (FOC.Ia - FOC.Ia_midpoint) * FOC_CURRENT_SCALE;
float ib = (FOC.Ib - FOC.Ib_midpoint) * FOC_CURRENT_SCALE;
float ic = (FOC.Ic - FOC.Ic_midpoint) * FOC_CURRENT_SCALE;
```

| 行 | 作用 |
|---|---|
| `FOC_CURRENT_SCALE = 3.3/(65536·0.005·20)` ≈ **0.504 mA/LSB** | 5 mΩ 分流 × 20 倍放大 → 满量程 ±16.5 A |
| `clarke_transform(ia, ib, ic, &i_alpha, &i_beta)` | 三相 → 两相静止：`Iα=Ia`、`Iβ=(Ib−Ic)/√3`（幅值不变换） |
| `park_transform(i_alpha, i_beta, phase, &i_d, &i_q)` | 静止 → 旋转：得到直流量 `Id/Iq`，方便 PI 无静差 |
| `i_d_err = Id_set - i_d; i_q_err = Iq_set - i_q;` | 误差（`Id_set` 恒为 0：表贴式不需要弱磁） |
| `v_d = i_d_err*kp + integral_d;` | **位置式 PI** 的比例+积分（积分项单独存） |
| `v_q = i_q_err*kp + integral_q;` | 同上 |
| `if (FOC.ff_enable && !FOC.calib_mode)` | 反电势前馈 + d/q 交叉解耦：`vd += -ωL·iq`、`vq += ω(L·id+λ)`。它把"耦合项"提前抵消，PI 只需管误差 |
| `FOC.Vd_out/Vq_out/Vmag` | 记录给波形用（**限幅前**的指令值） |
| `v_to_mod = 1.5f / FOC.Vbus_filt` | 电压 → 调制比：`mod = v·1.5/Vbus`（与 SVPWM 的归一化约定配套） |
| `factor = 0.9·√3/2 / sqrt(mod²)` | 矢量限幅：保证 `|mod| ≤ 0.779` → 最大相电压 `0.9·Vbus/√3`（留 10% 裕量） |
| `if (factor < 1) { 缩放; integral *= 0.99; }` | **抗积分饱和**：饱和时不累加积分，反而每拍衰减 1%（退饱和时不会残留大风量） |
| `else { integral += err·(ki·Ts); }` | 正常时才积分，`Ts = 50 µs` |
| `pwm_phase = phase + phase_vel*Ts` | **角度外推一拍**：补偿"采样→计算→下周期生效"的延迟（否则高速时驱动角滞后） |
| `inverse_park(mod_vd, mod_vq, pwm_phase, &alpha, &beta)` | 旋转 → 静止，得到 α/β 电压 |
| `SVPWM(alpha, beta, &dtc_a, &dtc_b, &dtc_c)` | 生成三相占空比（见 §6） |
| `foc_deadtime_comp(); pwm_set_duty(...)` | 死区补偿后写影子寄存器 |
| `FOC.Iq = i_q; UTILS_LP_FAST(Iq_filt, ...)` | 保存实际反馈值（`_filt` 是一阶低通，给显示/标定用，**不参与电流环**） |
| `FOC.torque = 1.5·Pn·λ·iq` | 转矩估算（表贴式 `T = 1.5·p·λ·iq`） |
| `FOC.Power_filt = 1.5(vd·id + vq·iq)` | 电磁功率估算 |

**几个容易误解的点**

- `kp` 与 `ki` 的关系：`kp = L·ωc`、`ki = R·ωc`，所以 PI 零点 `ki/kp = R/L` **正好抵消**电机电气极点
  （`R/L = 8.29/3.4mH → 388 Hz`），闭环近似一阶、带宽就是 `ωc`。
- 积分器是**位置式**，抗饱和靠"饱和时 ×0.99"而不是"停止累加"，简单但有效。
- `Iq` 是**未滤波**的值，`Iq_filt` 才是滤波值——波形上看到的是 `Iq`。

### 5.4 逐行讲解：`foc_deadtime_comp()`

```c
const float dt_comp = (float)DT_DEAD_NS * 1e-9f / CURRENT_MEASURE_PERIOD;  // 100ns/50µs = 0.002
float ca = ((FOC.Ia - midpoint) * SCALE) / DT_COMP_ITH;                    // 电流归一化
if (ca > 1) ca = 1; else if (ca < -1) ca = -1;                             // 限到 ±1
FOC.dtc_a += dt_comp * ca;                                                 // 按电流方向补偿占空比
```

| 行 | 作用 |
|---|---|
| `DT_DEAD_NS = PWM_DEAD_TIME_NS + 100` | 本板 PWM 外设死区设 0，实际死区来自 FD6288 的 **100 ns** |
| `dt_comp = 0.002` | 占空比补偿量：100 ns / 50 µs。24 V 下等效 **48 mV** |
| `ca = i / 0.8` | 用 `ITH=0.8 A` 做过零过渡带：`|i|>0.8 A` 时满额补偿，小电流时线性过渡（避免方波化产生啸叫） |
| `dtc_a += dt_comp * ca` | 电流为正时占空比加、为负时减（补偿"死区让实际电压少了一块"） |

### 5.5 `FOC_voltage()`（开环电压输出）

和 `FOC_current()` 的后半段一样（归一化→限幅→逆 Park→SVPWM→死区补偿→占空比），
**区别是没有电流 PI**，直接按给定 `Vd/Vq` 输出电压。标定（R/L/磁链/开环拖动）全用它。

### 5.6 增益更新 `FOC_update_current_ctrl_gain()`

```c
float bandwidth = bw * M_2PI;                              // Hz → rad/s
FOC.current_ctrl_p_gain = Config.phase_inductance * bandwidth;   // kp = L·ωc
FOC.current_ctrl_i_gain = Config.phase_resistance * bandwidth;   // ki = R·ωc
Config.current_kp = FOC.current_ctrl_p_gain;               // 存回配置
Config.current_ki = FOC.current_ctrl_i_gain;
Config.current_gain_magic = CONFIG_MAGIC;                  // 标记"有效"
```

`bw` 就是上位机的「电流带宽Hz」（USB 命令 **0x58**，限幅 50~2000 Hz），改完**立即生效**。

### 5.7 `foc_arm()` / `foc_disarm()`

- `foc_arm()`：检查 ADC 是否就绪 → 清电流/积分/功率 → `enable_bldc_pwm_output()` 恢复输出 →
  清故障码 → `is_armed = true`。**重新使能会顺带清掉故障码**（现在没有独立的"清故障"命令）。
- `foc_disarm()`：`disable_bldc_pwm_output()` 把六路强制成无效电平（**自由滑行，不是主动刹车**）→
  清状态 → `is_armed = false`。
- 两者都在 `taskENTER_CRITICAL()` 里做，避免和中断抢状态。

## 6. 坐标变换与 SVPWM `util.c`

### 6.1 Clarke / Park / 逆 Park

```c
void clarke_transform(...)   // Iα = Ia；Iβ = (Ib - Ic)/√3      —— 幅值不变换
void park_transform(...)     // Id = Iα·cosθ + Iβ·sinθ；Iq = -Iα·sinθ + Iβ·cosθ
void inverse_park(...)       // Vα = Vd·cosθ - Vq·sinθ；Vβ = Vd·sinθ + Vq·cosθ
```

`sin_f32/cos_f32` 是查表+插值的快速三角，比 `sinf` 快很多（20 kHz 中断里必须用）。

### 6.2 逐段讲解：`SVPWM()`

输入 `alpha/beta` 是**调制比**（`v·1.5/Vbus`），输出三相占空比（0~1）。

```c
if (beta >= 0) {
	if (alpha >= 0) {
		if (ONE_BY_SQRT3 * beta > alpha) Sextant = 2;
		else                             Sextant = 1;
	} else { ... }
} ...
```

| 步骤 | 作用 |
|---|---|
| 扇区判断 | 用 `α`、`β` 与 `β/√3` 比较，把平面分成 6 个 60° 扇区（只用比较，没有整除/查表，快） |
| 每扇区算 `t1/t2` | 两个相邻基本矢量的作用时间（归一化到周期） |
| `duty = (1 - t1 - t2)*0.5` | 零矢量平均分给两端（七段式的对称写法） |
| 返回 0/-1 | `-1` 表示过调制/非法值 → 调用方**不更新占空比**（保持上一拍，避免炸波形） |

**调制比与相电压的关系**（推导结论，便于核对）：
`mod = v·1.5/Vbus` → 实际相电压幅值 = `(2/3)·mod·Vbus = v` ✓；
限幅 `|mod| ≤ 0.9·√3/2` → 最大相电压 `0.9·Vbus/√3`。

## 7. 编码器 `encoder.c`（MT6835 + PLL）

### 7.1 作用与逻辑

- **SPI1 + DMA** 双缓冲读 MT6835（21 位角度），5 kHz 更新一次。
- 原始角度先做**方向修正**，再累加成多圈位置 `shadow_count`。
- 用**标定得到的零位偏移 + 512 点线性度 LUT** 对齐成 `count_aligned`。
- `phase = count_aligned × 极对数 mod 2^21 → 电角度`。
- **PLL** 把离散角度变成平滑的 `vel`（速度环用），并带"静止死区"防漂。

### 7.2 逐行讲解：`ENCODER_loop()`

```c
raw = (rx_buf[2]<<16) | (rx_buf[3]<<8) | (rx_buf[4]&0xF8);   // 21 位角度在高位
corrected = (Config.encoder_dir == 1) ? raw : (ENCODER_MASK - raw);  // 方向修正
```

| 行 | 作用 |
|---|---|
| `if (encoder.need_init > 0)` | 上电前几拍只对齐 `pll_pos`，不累加、不跑 PLL（防止第一帧当跳变） |
| `delta = corrected - count_in_cpr_prev` + `±CPR` 修正 | 单圈差分遇到过零要折返，否则在 0/2^21 处会出现巨大跳变 |
| `encoder.shadow_count += delta` | 累加成多圈位置（int64，可正可负） |
| `lut_index = corrected * OFFSET_LUT_NUM / ENCODER_CPR` | 查 512 点线性度表的位置 |
| `aligned_count = corrected - Config.encoder_offset - Config.offset_lut[lut_index]` | 减零位、再减 LUT 误差 → 与校准零位对齐的角度 |
| `encoder.phase = ((count_aligned * Pn) & MASK) * 2π/CPR` | 机械角 × 极对数 → 电角度（Q15 位运算取模） |
| `pos_err = count - pll_pos`（±半圈归一化） | PLL 的相位误差 |
| `pll_pos += (pll_vel + kp·pos_err)·Ts` | **PI-PLL 的相位积分**（二阶环路） |
| `pll_vel += (ki·pos_err)·Ts` | 速度积分（`kp = 2ωbw`、`ki = 0.25kp²`，`bw = 300 Hz`） |
| `if (|pll_vel| < snap_threshold) pll_vel = 0` | **静止死区**（≈1 rpm）：静止时角度量化噪声会让积分器慢慢漂，直接清零 |
| `encoder.vel = pll_vel / CPR` | 转成 rps（**外环用的就是它**） |
| `encoder.phase_vel = vel·2π·Pn` | 电角速度（前馈解耦、角度外推用） |

## 8. 外环 `foc_ctrl.c`

### 8.1 作用与逻辑

`CONTROLLER_loop()` 在 5 kHz 任务里跑，按模式算出 `FOC.Iq_set`：

| 模式 | 逻辑 |
|---|---|
| `CURRENT_RAMP`（0） | 电流指令按 `current_ramp_rate` 斜坡逼近 → `cur_setpoint` |
| `VELOCITY_RAMP`（1） | 速度指令按 `velocity_ramp_rate` 斜坡 → 速度 PI → 电流 |
| `POSITION_FILTER`（2） | 位置 P：`vel_des = pos_p_gain·(目标角-实际角)` → 速度 PI |
| `POSITION_PROFILE`（3） | 目前**复用位置滤波**（`profile_*` 参数还没用） |

### 8.2 逐行讲解：`CONTROLLER_loop()` 主干

```c
tFSMState stage = foc_get_stage();

if ((stage == IDLE) || (stage == RUN)) {          // 模式切换/回零请求只能在任务上下文执行
	if (Controller.op_mode_pending) { ... CONTROLLER_set_op_mode(...); }
	if (Controller.home_pending)  { ... CONTROLLER_set_home(); }
}
```

| 行 | 作用 |
|---|---|
| `if (Controller.config_cmd_pending != 0)` | 存/恢复默认配置：**必须先失能**（擦写 Flash 要关中断几十 ms），所以会在 armed 时拒绝 |
| `if (stage != RUN && stage != ANTICOGGING) return;` | 只有运行态（和齿槽标定态）才跑外环 |
| `switch (ctrl_mode)` 电流模式 | `max_step = ramp_rate·Ts`，用 `CLAMP` 限制每次变化量 → 电流软启动 |
| 速度模式 | 速度指令斜坡 + `cur_setpoint = current_ff_gain·(step/Ts)`（加速度前馈，默认 0.001≈关闭） |
| 位置模式 | `perr` 卷绕到 ±π；`pos_setpoint = 实测角`；`vel_des = pos_p_gain·perr` |
| `if (ctrl_mode < POSITION_FILTER) vel_des = vel_setpoint;` | 速度和电流模式用坡道后的速度指令；位置模式的速度目标已经在上一段算好 |
| `vel_des = CLAMP(vel_des, ±velocity_limit)` | 速度限幅（配置里的 `velocity_limit`） |
| `vel_kp/vel_ki` + `boost` | 低速增益调度：`VEL_BOOST_GAIN=1.0` → **当前等于关闭**（留了扩展） |
| `v_err = vel_des - vel_meas; iq_set += kp·v_err + integrator` | 速度 PI（输出就是电流指令，单位 A） |
| `if (ctrl_mode < VELOCITY_RAMP)` 的速度限幅 | 电流模式下用"离速度上限还有多远"限制电流，防止电流模式冲飞 |
| 摩擦前馈 | `|vel|<0.01` → 用 BREAK 0.05 A；`|vel|>0.05` → 用 MOVE 0.03 A；按 `vel_des` 方向加。**0.1 rps 实测开关差异很小**，可用 0x2B 关掉做 A/B |
| 齿槽前馈 | 用 `count_aligned` 查 512 点表、相邻点线性插值，`iq_set += cg/5000`（表值单位是 1/5000 A） |
| 电流限幅 | `|iq_set| ≤ current_limit`，并置 `limited` 标记 |
| `FOC.Id_set = 0; FOC.Iq_set = iq_set;` | **交给 20 kHz 电流环** |
| 速度积分器 | `limited` 时 ×0.99（抗饱和）；否则 `integrator += vel_ki·Ts·v_err`；最后 `CLAMP(±0.5 A)` |
| 电流模式 | 积分器清零（电流模式不该有速度积分残留） |

### 8.3 三个"辅助机制"的定位

| 机制 | 什么时候起作用 | 备注 |
|---|---|---|
| 摩擦前馈 | 速度/位置模式、非齿槽标定态 | 解决低速静摩擦"粘住不动" |
| 齿槽前馈 | 速度/位置模式、`cogging_map_valid=1` | 用 0x2E 扫描标定出来的表 |
| 低速增益调度 | 速度/位置模式 | 目前增益=1，等于关闭 |

### 8.4 其它函数

- `CONTROLLER_sync_callback()`：USB 中断里调用，把"缓冲值"锁存到"输入值"（USB 中断不能直接改
  控制变量，否则会被 5 kHz 循环读撕裂）。**只在 RUN 态生效**。
- `CONTROLLER_set_home()`：IDLE 时直接清 `shadow_count`；RUN 时必须"速度<0.5 rps 且位置误差<0.01"
  才允许置零（防止运行中误操作把位置清零）。
- `CONTROLLER_reset()`：把输入/设定/积分全部对齐到实测位置和 0 速度——**切模式、使能、标定前都要调**，
  否则旧状态会带进新模式。

## 9. 任务与状态机 `foc_task.c`

### 9.1 状态机

| 状态 | 进入 | 循环 | 退出 |
|---|---|---|---|
| `BOOT_UP` | 上电 | 记录"中点已标定"标记 | 由请求切走 |
| `IDLE` | 默认/停机 | 允许齿槽表 dump | 收到使能/标定请求 |
| `RUN` | 使能 | 保护检测 | 失能/故障/标定请求 |
| `CALIBRATION` | 0x27 | 1 kHz 跑标定状态机 + 保护 | 标定结束 |
| `ANTICOGGING` | 0x28 / 0x2E | 1 kHz 跑齿槽标定 + 保护 | 标定结束 |

`enter_state()` / `exit_state()` 里做初值与收尾（例如进入 CALIBRATION 调 `calibration_start()`，
退出时 `calibration_end()`）。

### 9.2 逐行讲解：`Task_FOC()`

```c
for (;;) {
	tick++;
	bool slow_tick = ((tick % 5U) == 0U);      // 5kHz 里每 5 拍做一次 1kHz 的活
	if (s_req_valid) { ... }                    // 处理中断/其它任务提交的状态请求
	if (sFSM.state_next != sFSM.state) { exit_state(); enter_state(); }
	if (slow_tick) foc_update_voltages();       // 1kHz: 三相/母线电压、母线电流
	switch (sFSM.state) { ... }                 // 各状态的周期动作
	CONTROLLER_loop();                          // 5kHz: 外环
	vTaskDelayUntil(&last, 2);                  // 10kHz tick → 0.2ms → 5kHz
}
```

| 行 | 作用 |
|---|---|
| `if (slow_tick) cogging_dump_loop()` | 齿槽表分块打印（每拍 8 点，避免阻塞） |
| `case RUN: foc_check_and_trip()` | 运行态每拍都做保护检测 |
| `case CALIBRATION: calibration_loop()` | 1 kHz 标定状态机 |
| `case ANTICOGGING: anticogging_loop()` | 1 kHz 齿槽标定（返回 true 表示结束 → 回 IDLE） |
| `CONTROLLER_loop()` 放在 switch 之后 | 即使保护刚触发（切 IDLE），也先把外环跑完，保证状态一致 |

### 9.3 保护逻辑 `foc_protection_check()` / `foc_check_and_trip()`

| 保护 | 判据 | 去抖 |
|---|---|---|
| 相过流 | 任一相 `|I| > protect_over_current` | **立即**（0 拍） |
| 母线过流 | `Ibus_filt > protect_i_bus_max` | 3 拍 |
| 母线过压 | `Vbus > protect_over_voltage` | 3 拍 |
| 母线欠压 | `Vbus < protect_under_voltage` | 20 拍（防上电瞬间误报） |
| ADC 故障 | 母线电压不在 2~70 V / 电流坏帧≥3 / 电压坏帧≥3 / 母线坏帧≥3 | — |
| 采样停更 | `adc_current_frames` 10 ms 没变化 | 按**真实时间**判（任务补跑时按次数会误报） |

欠压还有一个"自适应禁用"：若配置的欠压阈值比实测母线还高（例如 24 V 母线但 Flash 里存着 15 V 的旧阈值），
打印警告并**跳过欠压保护**，避免一上电就跳。

触发后：`FOC.fault_code = fault` → `foc_disarm()` → `foc_request_stage(IDLE)`。

## 10. 参数与 Flash `config.c`

### 10.1 结构

- `tConfig` 里所有参数 + 尾部 `crc32`。
- **CRC 只覆盖 `offsetof(tConfig, crc32)` 之前的部分** → 之后的字段（`current_kp/ki`、
  `if_*`、`mech_*`）是"追加区"，用各自的 magic 判断有效性，这样旧 Flash 记录仍能加载。
- `CONFIG_save_to_flash()` / `CONFIG_load_from_flash()`：擦写固定扇区，带版本 magic 校验。

### 10.2 默认值（24 V 系统，2026-11）

| 参数 | 值 | 备注 |
|---|---|---|
| `phase_resistance` | **8.29 Ω** | 相值；万用表相间 16.86 Ω 的一半 |
| `phase_inductance` | **3.4 mH** | 标定 3.1~3.5 mH |
| `current_limit` | 1.5 A | ≈0.41 N·m |
| `calib_current` / `calib_voltage` | 0.5 A / 10 V | 24 V 母线专用 |
| `current_ctrl_bw` | **300 Hz** | 电流环带宽 |
| `vel_p_gain` / `vel_i_gain` | 0.17 / 5.3 | A/rps、A/(rps·s) |
| `pos_p_gain` | 5.0 | 位置 P |
| `protect_under/over_voltage` | 18 V / 28 V | 24 V 母线 |
| `protect_over_current` | 2.0 A | 额定的 2.2 倍 |

> ⚠️ 改结构体布局（增删 `crc32` 之前的字段）会让旧 Flash 配置 CRC 失效 → 自动回默认值，
> **标定数据会丢**。追加字段请放在 `crc32` 之后。

## 11. 通信 `vofa.c` / `usb_driver.c`

### 11.1 波形 `vofa.c`

- `VOFA_NCH = 22`：22 个 float 通道，Justfloat 格式（帧尾 `0x00 0x00 0x80 0x7f`）。
- 20 kHz 中断里 `vofa_push_sample()` 按 4 分频（5 kHz）取快照进环形缓冲；
  `vofa_task` 每 1 ms 把一批打包发 USB（有效采样率与 USB 包率解耦）。
- **通道名来自 `vofa_snapshot()` 里的 `/* 显示名 (单位) */` 注释** —— 上位机启动时解析这段源码
  自动命名，所以改通道名/顺序要同时考虑上位机。

### 11.2 命令 `usb_driver.c`

- 帧格式：固定 **5 字节** = `[命令码 1B][float32 小端 4B]`。
- `USB_parse_frame()` **在 USB 中断里执行**：只允许"设标志/写简单变量"，不能 printf、不能擦 Flash。
  - 模式切换 → `Controller.op_mode_req + pending`（交给任务执行）
  - 存/恢复配置 → `Controller.config_cmd_pending = 1/2`
  - 标定 → `foc_request_stage(CALIBRATION)`
- 常用命令表：

| 码 | 含义 |
|---|---|
| 0x20 / 0x21 / 0x22 | 设模式 / 使能 / 失能 |
| 0x23 / 0x24 / 0x25 | 电流 / 速度 / 位置指令 |
| 0x27 / 0x28 / 0x2E | 参数标定 / 齿槽标定(位置保持) / 齿槽扫描 |
| 0x2A / 0x2B / 0x2C | 齿槽补偿开关 / 摩擦前馈开关 / dump 齿槽表 |
| 0x2D | 当前位置置零 |
| 0x3E / 0x3F / 0x3B | 读参数 / 存 Flash / 恢复默认 |
| 0x40~0x44 | 电流 Kp/Ki、速度 Kp/Ki、位置 Kp |
| **0x58** | **设电流环带宽 (Hz)** |
| 0x50~0x55（遗留） | 手写 I/F 强拖参数（已不参与控制，等待清理） |

## 12. 标定 `foc_cal.c` 概览

1 kHz 状态机，一次完整标定（0x27）依次跑：

| 步骤 | 方法 | 输出 |
|---|---|---|
| `CS_MOTOR_R_*` | d 轴电压逐级升压，**多点平均 ΔI** 求 R | `phase_resistance` |
| `CS_MOTOR_L_*` | α 轴正弦注入（频率 = `current_ctrl_bw`），解调得阻抗 Z → `L=√(Z²-R²)/ω` | `phase_inductance` |
| `CS_DIR_PP_*` | 开环拖动一圈，比较电角度/机械角 → 方向 + 极对数 | `invert_motor_dir`、`pole_pairs` |
| `CS_ENCODER_*` | 正反各转一圈，拟合零位偏移；再扫 512 点建线性度 LUT | `encoder_offset`、`offset_lut` |
| `CS_FLUX_*` | 两个转速点测 Vd/Vq，**矢量差分**消掉 R 项 → λ | `flux_linkage` |
| `CS_MOTOR_J_*` | 加速段 + **断电流自由滑行**段，最小二乘拟合斜率 → J | 只打印（master 无 J 字段） |
| 齿槽（0x28 / 0x2E） | 位置保持法 / 恒速扫描法 | `cogging_map` + `cogging_map_valid` |

**改带宽的连锁反应**：`FOC.vinj_omega = 2π·current_ctrl_bw` → 提高带宽会让 L 的注入频率变高，
`Z/R` 变大、L 测得更准（300 Hz 时 Z/R=1.26，1 kHz 时 2.8）。所以**先定带宽、再标定**。

| 齿槽表 | 512 点，1/5000 A/LSB | `config.h` |

## 14. 改动注意点（含电流环带宽）

### 14.1 想把电流环带宽从 300 Hz 提高

| 事实 | 数值 |
|---|---|
| 电机电气极点 `R/(2πL)` | **388 Hz**（300 Hz 带宽其实在极点以下） |
| 环路延迟 | 采样→计算→reload 生效 ≈ **50~70 µs**（约 1.5 个 PWM 周期） |
| 1 kHz 交叉时的相位损失 | ≈ −22°，相位裕度 ≈ 68° |
| 理论可行上限 | **1.2~1.5 kHz** |

**改动方式**：上位机「电流带宽Hz」→ USB 0x58（`FOC_update_current_ctrl_gain()`），**在线生效不用重烧**。

**验证要点**：
1. 用「电流」模式做 0.1→0.5 A 阶跃，看 `Iq` 的上升时间与超调（`tr ≈ 0.35/fc`）
2. 同时看 `saturated`（11 通道）有没有频繁置位
3. 高速/大电流下注意 `Vd/Vq` 是否顶到 `0.9·Vbus/√3`
4. **改完带宽要重新标定 L**（注入频率跟着变）
5. 5 kHz 记录对 800 Hz 以上只剩 2~3 点/上升沿 → 更高带宽建议扫频法

### 14.2 其它容易踩的点

| 想改什么 | 要注意 |
|---|---|
| 加/删通道 | 同步改 `VOFA_NCH`、上位机 `NCH`、`scope_cfg.json`（通道注释会被上位机解析） |
| 改 `Config` 结构 | 只能往 `crc32` **之后**追加，否则旧 Flash 配置失效、标定丢失 |
| 改 `COGGING_MAP_NUM` | 表大小影响 Flash 布局和插值索引，改了要重标 |
| 加新的 USB 命令 | 在 USB 中断里执行：只置标志，重活丢给任务 |
| 改 PWM/ADC 时序 | 三处必须一起核对：SVPWM 归一化、电流采样时刻、死区补偿量 |
| 外环频率 | `CTRL_PERIOD` 与 `vTaskDelayUntil` 必须一致，否则所有斜坡速率都错 |

## 附：建议的阅读顺序（约 3 小时吃透核心）
